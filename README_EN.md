Do you often encounter these paint points when browsing, reading research papers, working, or creating content?
* 🔋 Flooded browser extension bar with shortcut conflicts and messy interactions;
* 🔒 Worrying that sensitive webpage data is uploaded by various online AI or translation tools, compromising privacy;
* 💰 Tedious paid tools or vendor lock-in with a single AI provider, lacking customization.

**KnowIt** is designed to address these problems. It is a completely local-running, privacy-first modular suite of browser productivity tools. With an innovative **built-in App Marketplace**, you can install or uninstall various small tools like building blocks to craft your own **"Web Super Workstation"**.

---

## ✨ Core Highlights

* **🧩 Modular App Marketplace**: Move away from bloated "all-in-one" extensions. Easily install/uninstall text search, AI summary, selection translation, media downloader, etc., from the built-in marketplace to keep your extension light and fast.
* **🔒 Ultimate Privacy Protection**: All web parsing, selection text, search history, translation history, etc., are stored only in your local browser storage or IndexedDB. No data is ever uploaded to any third-party servers.
* **🔑 Bring Your Own API Key**: Unified model configuration center where you can bind your own API Keys. Supports DeepSeek, OpenAI, Gemini, Moonshot (Kimi), Alibaba DashScope, SiliconFlow, and most other mainstream LLM providers.
* **🎨 Elegant Interaction & Dark Mode**: Exquisite UI supporting floating toolbars, keyboard shortcuts, and sidebar views. Adapts beautifully to dark and light modes.

---

## 🛠️ Feature Showcase

### 🧩 Productivity Tools

* **🔍 Enhanced Text Search**: Powerful page text search supporting multi-keyword highlights, making long reading effortless.
* **📄 Smart Page Exporter**: Extract clean article text, export to Markdown, PDF, HTML, or images while preserving layout and math formulas.
* **📥 Web Media Downloader**: Automatically sniff and batch download images, videos, audios, or PDF documents with multi-criteria filters.

### 🤖 AI Smart Assistants

* **📝 Web AI Summarization**: Extract outlines and key takeaways of long web pages, articles, or research papers in seconds.
* **🌐 Bilingual Selection Translation**: Translate any selected paragraph or term with clean side-by-side bilingual display.
* **📖 Vocabulary Inspector**: Designed for language learners. Show pronunciation, translations, definitions, example sentences, and save words to a local notebook.
* **✍️ Smart Writing & Polishing**: Call AI inline to expand, shorten, polish, check grammar, or execute custom prompts on any input field.

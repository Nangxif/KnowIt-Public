## 簡介

在日常瀏覽網頁、閱讀文獻、工作學習或內容創作時，你是否常遇到以下痛點？

* 瀏覽器插件欄日益臃腫，不同插件快捷鍵衝突、交互凌亂；
* 擔心敏感網頁數據被各類在線 AI 或翻譯工具上傳，洩露隱私；
* 各種小工具收費繁瑣，或綁定單一 AI 廠商，缺乏定制靈活性。

**KnowIt** 是一款完全運行在本地、隱私優先的模組化瀏覽器效率工具集。點擊擴展圖標進入**工作臺**，你可以像搭積木一樣自由安裝或卸載各項小工具，打造最符合個人工作流的「網頁超級工作臺」。

**核心特點：**

* **模組化工作臺**：按需安裝，保持擴展輕量流暢
* **隱私優先**：網頁內容、選中文字、搜索與生成記錄默認只存本地，不上傳至 KnowIt 服務器
* **自備 API Key**：統一模型配置中心，支持 DeepSeek、OpenAI、Gemini、Moonshot (Kimi)、阿里雲百煉、SiliconFlow 等主流大模型
* **優雅交互**：支持快捷鍵、右鍵菜單、劃詞懸浮工具欄、側邊欄、工作臺、新標籤頁，以及深淺色模式

## 3.0.0 新變化

當前版本為 **3.0.0**（2026-09-01）。相對 2.x，主要變化如下：

* **工作臺重做**：擴展首頁改為左右分欄工作臺，應用安裝、模型配置、工具欄、黑名單、同步、激活和數據統計都在同一頁完成
* **新標籤頁重做**：打開新標籤即可搜索網頁、直達常用大模型對話，並查看每日熱點
* **歷史記錄重做**：總結、翻譯、識字、寫作、導出記錄挪到工作臺中集中回看
* **新增免費應用「廣告清除」**：授權後自動隱藏網頁廣告與推廣浮層，支持右鍵清除 / 恢復與撤銷
* **新增免費應用「元素檢查器」**：檢查頁面元素屬性，並用取色器吸取任意像素色
* **劃詞翻譯支持放大查看**：譯文可放大到側邊欄閱讀
* **穩定性**：修復未啟用應用時樣式仍影響原網頁、資源下載器無法打開的問題。若你仍在使用 2.3.0，建議盡快升級

## 工作臺與新標籤頁

安裝擴展後，點擊瀏覽器工具欄中的 KnowIt 圖標即可打開**工作臺**。先在工作臺安裝需要的應用，再按下方方式使用。

### 工作臺

工作臺是 KnowIt 的控制中心：

* 瀏覽、安裝、卸載應用，並進入各應用設置
* 配置 AI 模型、劃詞工具欄、插件黑名單與跨設備同步
* 完成終身版激活
* 查看使用統計與全部歷史記錄

默認已裝好**文字搜索**、**資源下載器**和**廣告清除**，其他能力可按需添加。

### 新標籤頁

每次打開新標籤頁，都可以：

* 搜索網頁
* 一鍵進入 DeepSeek、Kimi、通義千問、豆包、ChatGPT、Claude、Gemini、元寶等常用大模型對話
* 查看每日熱點

### 歷史記錄

AI 總結、劃詞翻譯、劃詞識字、智能寫作與頁面導出的記錄保存在本地，可在工作臺中按工具類型回看原文與結果。新標籤頁不再展示歷史記錄。

## 應用清單與使用方式

### 免費應用

#### 1. 文字搜索（默認已安裝）

* **做什麼**：像代碼編輯器一樣搜索網頁文字，支持大小寫匹配、結果跳轉與自定義高亮。
* **怎麼用**：
  1. 在任意網頁按下默認快捷鍵 `Ctrl + F`（Mac 為 `⌘ + F`）打開搜索框
  2. 輸入關鍵詞進行定位與高亮
  3. 可在應用設置中自定義快捷鍵與高亮樣式

#### 2. 資源下載器（默認已安裝）

* **做什麼**：一鍵掃描並提取網頁中的圖片、視頻等資源，支持預覽與批量下載。
* **怎麼用**：
  1. 在網頁空白處右鍵，選擇 **資源下載器**
  2. 在側邊欄中篩選、預覽並批量下載

#### 3. 廣告清除（默認已安裝）

* **做什麼**：隱藏當前網頁上的廣告和推廣浮層，讓閱讀更乾淨。打開網頁即可自動清除，也可右鍵操作，支持撤銷。這是頁內隱藏，不會攔截網絡請求。
* **怎麼用**：
  1. 首次使用時完成授權（引導頁可一鍵開啟）；未授權時不會自動工作
  2. 授權後，之後打開的網頁會自動隱藏廣告；已經打開的頁面刷新一次即可生效
  3. 也可在網頁空白處右鍵，選擇 **清除本頁廣告** 或 **恢復本頁廣告**
  4. 可在應用設置中關閉「打開網頁時自動清除」，或關閉「持續隱藏後續出現的廣告」

#### 4. 元素檢查器

* **做什麼**：點擊頁面元素查看類似 Figma 的屬性面板，並用取色器吸取頁面任意像素色。
* **怎麼用**：
  1. 在工作臺安裝「元素檢查器」
  2. 在網頁空白處右鍵選擇 **檢查頁面元素**，或按下默認快捷鍵 `Alt+Shift+C`
  3. 懸停查看屬性，點擊可鎖定；底部工具條切換檢查 / 取色
  4. 按 `Esc` 退出檢查

### 付費應用（需激活終身版）

#### 5. 頁面導出

* **做什麼**：整理網頁正文並導出為 Markdown，保存乾淨、可編輯的副本。
* **怎麼用**：
  1. 安裝並確保已激活
  2. 在網頁空白處右鍵，選擇 **生成 Markdown**
  3. 在側邊欄查看、編輯並導出結果；可在設置頁調整導出相關選項

#### 6. 內容總結

* **做什麼**：用 AI 總結整篇網頁或選中內容，快速提煉重點與核心結論。
* **怎麼用**：
  1. 先在工作臺「AI 模型配置」中填好 API Key，並在該應用設置中選擇模型
  2. **整頁總結**：右鍵網頁，選擇 **AI總結**
  3. **劃詞總結**：選中文字後，在懸浮工具欄點擊 **總結**（可在工作臺「工具欄顯示」中開啟）
  4. 結果在側邊欄展示，可暫停生成並查看歷史記錄

#### 7. 劃詞翻譯

* **做什麼**：選中文字即時翻譯；也可對整頁進行 AI 對照翻譯，減少來回切頁。譯文支持放大到側邊欄查看。
* **怎麼用**：
  1. 配置模型後安裝應用
  2. **劃詞翻譯**：選中文字，點擊懸浮工具欄 **翻譯**；需要時點擊 **放大查看**
  3. **全文翻譯**：右鍵網頁，選擇 **AI 全文翻譯**
  4. 也可用快捷鍵翻譯剪貼板，或在翻譯側欄粘貼後按 `⌘/Ctrl + Enter`
  5. 可在應用設置中調整目標語言與模型

#### 8. 劃詞識字

* **做什麼**：選中網頁文字後，快速展示拼音與詞義解釋，輔助閱讀與學習。
* **怎麼用**：
  1. 配置模型後安裝應用
  2. 選中文字，在懸浮工具欄點擊 **識字**
  3. 在面板中查看讀音與釋義；可在設置頁管理模型與歷史

#### 9. 智能寫作與潤色

* **做什麼**：在網頁輸入框中調用 AI，進行潤色、糾錯、續寫、擴寫、精簡或自定義 Prompt 創作。
* **怎麼用**：
  1. 配置模型後安裝應用，並在設置中開啟輸入框寫作助手
  2. 聚焦任意輸入框 / 文本域，右下角出現懸浮助手按鈕
  3. 選擇預設（潤色、糾錯、續寫、擴寫、精簡等）或輸入自定義指令
  4. 可將結果替換原文、插入或複製

4. **（可選）配置 AI**  
   在工作臺打開「AI 模型配置」，添加廠商、模型名稱、接口地址與 API Key，並設為默認模型。各 AI 應用可在各自設置頁單獨指定模型。

5. **（可選）購買激活**  
   前往[愛發電支付](https://ifdian.net/order/create?product_type=1&plan_id=bb5efc0a8f0c11f181ee52540025c377&sku=%5B%7B%22sku_id%22%3A%22bb66d6fa8f0c11f1bada52540025c377%22,%22count%22%3A1%7D%5D&viokrz_ex=0)完成支付，回到工作臺「購買激活」填寫郵箱與訂單號。

6. **開始使用**  
   通過快捷鍵、右鍵菜單、劃詞懸浮工具欄或新標籤頁調用已安裝應用。

## 使用須知

* **數據離線處理**：網頁內容、選中文字、搜索記錄、總結與生成結果等，默認僅在本地處理，不會上傳至 KnowIt 服務器。
* **API Key 僅保存在本地**：自行配置的密鑰只存在於當前瀏覽器本地配置中。
* **配置同步**：應用安裝狀態、偏好設置等，可能通過瀏覽器同步能力跟隨 Google 賬號同步。
* **激活限制**：每個愛發電訂單號與綁定郵箱最多激活 2 次，請妥善保管。
* **第三方模型服務**：使用 AI 功能時，請求會發送至你配置的模型服務商。
* **廣告清除邊界**：廣告清除只隱藏頁面節點，不攔截廣告請求；視頻內廣告、反廣告攔截牆，以及缺少明顯廣告特徵的原生推廣可能清不掉。

## 简介

在日常浏览网页、阅读文献、工作学习或内容创作时，你是否常遇到以下痛点？

* 浏览器插件栏日益臃肿，不同插件快捷键冲突、交互凌乱；
* 担心敏感网页数据被各类在线 AI 或翻译工具上传，泄露隐私；
* 各种小工具收费繁琐，或绑定单一 AI 厂商，缺乏定制灵活性。

**KnowIt** 是一款完全运行在本地、隐私优先的模块化浏览器效率工具集。点击扩展图标进入**工作台**，你可以像搭积木一样自由安装或卸载各项小工具，打造最符合个人工作流的「网页超级工作台」。

**核心特点：**

* **模块化工作台**：按需安装，保持扩展轻量流畅
* **隐私优先**：网页内容、选中文字、搜索与生成记录默认只存本地，不上传至 KnowIt 服务器
* **自备 API Key**：统一模型配置中心，支持 DeepSeek、OpenAI、Gemini、Moonshot (Kimi)、阿里云百炼、SiliconFlow 等主流大模型
* **优雅交互**：支持快捷键、右键菜单、划词悬浮工具栏、侧边栏、工作台、新标签页，以及深浅色模式

## 3.0.0 新变化

当前版本为 **3.0.0**（2026-09-01）。相对 2.x，主要变化如下：

* **工作台重做**：扩展首页改为左右分栏工作台，应用安装、模型配置、工具栏、黑名单、同步、激活和数据统计都在同一页完成
* **新标签页重做**：打开新标签即可搜索网页、直达常用大模型对话，并查看每日热点
* **历史记录重做**：总结、翻译、识字、写作、导出记录挪到工作台中集中回看
* **新增免费应用「广告清除」**：授权后自动隐藏网页广告与推广浮层，支持右键清除 / 恢复与撤销
* **新增免费应用「元素检查器」**：检查页面元素属性，并用取色器吸取任意像素色
* **划词翻译支持放大查看**：译文可放大到侧边栏阅读
* **稳定性**：修复未启用应用时样式仍影响原网页、资源下载器无法打开的问题。若你仍在使用 2.3.0，建议尽快升级

## 工作台与新标签页

安装扩展后，点击浏览器工具栏中的 KnowIt 图标即可打开**工作台**。先在工作台安装需要的应用，再按下方方式使用。

### 工作台

工作台是 KnowIt 的控制中心：

* 浏览、安装、卸载应用，并进入各应用设置
* 配置 AI 模型、划词工具栏、插件黑名单与跨设备同步
* 完成终身版激活
* 查看使用统计与全部历史记录

默认已装好**文字搜索**、**资源下载器**和**广告清除**，其他能力可按需添加。

### 新标签页

每次打开新标签页，都可以：

* 搜索网页
* 一键进入 DeepSeek、Kimi、通义千问、豆包、ChatGPT、Claude、Gemini、元宝等常用大模型对话
* 查看每日热点

### 历史记录

AI 总结、划词翻译、划词识字、智能写作与页面导出的记录保存在本地，可在工作台中按工具类型回看原文与结果。新标签页不再展示历史记录。

## 应用清单与使用方式

### 免费应用

#### 1. 文字搜索（默认已安装）

* **做什么**：像代码编辑器一样搜索网页文字，支持大小写匹配、结果跳转与自定义高亮。
* **怎么用**：
  1. 在任意网页按下默认快捷键 `Ctrl + F`（Mac 为 `⌘ + F`）打开搜索框
  2. 输入关键词进行定位与高亮
  3. 可在应用设置中自定义快捷键与高亮样式

#### 2. 资源下载器（默认已安装）

* **做什么**：一键扫描并提取网页中的图片、视频等资源，支持预览与批量下载。
* **怎么用**：
  1. 在网页空白处右键，选择 **资源下载器**
  2. 在侧边栏中筛选、预览并批量下载

#### 3. 广告清除（默认已安装）

* **做什么**：隐藏当前网页上的广告和推广浮层，让阅读更干净。打开网页即可自动清除，也可右键操作，支持撤销。这是页内隐藏，不会拦截网络请求。
* **怎么用**：
  1. 首次使用时完成授权（引导页可一键开启）；未授权时不会自动工作
  2. 授权后，之后打开的网页会自动隐藏广告；已经打开的页面刷新一次即可生效
  3. 也可在网页空白处右键，选择 **清除本页广告** 或 **恢复本页广告**
  4. 可在应用设置中关闭「打开网页时自动清除」，或关闭「持续隐藏后续出现的广告」

#### 4. 元素检查器

* **做什么**：点击页面元素查看类似 Figma 的属性面板，并用取色器吸取页面任意像素色。
* **怎么用**：
  1. 在工作台安装「元素检查器」
  2. 在网页空白处右键选择 **检查页面元素**，或按下默认快捷键 `Alt+Shift+C`
  3. 悬停查看属性，点击可锁定；底部工具条切换检查 / 取色
  4. 按 `Esc` 退出检查

---

### 付费应用（需激活终身版）

#### 5. 页面导出

* **做什么**：整理网页正文并导出为 Markdown，保存干净、可编辑的副本。
* **怎么用**：
  1. 安装并确保已激活
  2. 在网页空白处右键，选择 **生成 Markdown**
  3. 在侧边栏查看、编辑并导出结果；可在设置页调整导出相关选项

#### 6. 内容总结

* **做什么**：用 AI 总结整篇网页或选中内容，快速提炼重点与核心结论。
* **怎么用**：
  1. 先在工作台「AI 模型配置」中填好 API Key，并在该应用设置中选择模型
  2. **整页总结**：右键网页，选择 **AI总结**
  3. **划词总结**：选中文字后，在悬浮工具栏点击 **总结**（可在工作台「工具栏显示」中开启）
  4. 结果在侧边栏展示，可暂停生成并查看历史记录

#### 7. 划词翻译

* **做什么**：选中文字即时翻译；也可对整页进行 AI 对照翻译，减少来回切页。译文支持放大到侧边栏查看。
* **怎么用**：
  1. 配置模型后安装应用
  2. **划词翻译**：选中文字，点击悬浮工具栏 **翻译**；需要时点击 **放大查看**
  3. **全文翻译**：右键网页，选择 **AI 全文翻译**
  4. 也可用快捷键翻译剪贴板，或在翻译侧栏粘贴后按 `⌘/Ctrl + Enter`
  5. 可在应用设置中调整目标语言与模型

#### 8. 划词识字

* **做什么**：选中网页文字后，快速展示拼音与词义解释，辅助阅读与学习。
* **怎么用**：
  1. 配置模型后安装应用
  2. 选中文字，在悬浮工具栏点击 **识字**
  3. 在面板中查看读音与释义；可在设置页管理模型与历史

#### 9. 智能写作与润色

* **做什么**：在网页输入框中调用 AI，进行润色、纠错、续写、扩写、精简或自定义 Prompt 创作。
* **怎么用**：
  1. 配置模型后安装应用，并在设置中开启输入框写作助手
  2. 聚焦任意输入框 / 文本域，右下角出现悬浮助手按钮
  3. 选择预设（润色、纠错、续写、扩写、精简等）或输入自定义指令
  4. 可将结果替换原文、插入或复制

## 使用须知

* **数据离线处理**：网页内容、选中文字、搜索记录、总结与生成结果等，默认仅在本地处理，不会上传至 KnowIt 服务器。
* **API Key 仅保存在本地**：自行配置的密钥只存在于当前浏览器本地配置中。
* **配置同步**：应用安装状态、偏好设置等，可能通过浏览器同步能力跟随 Google 账号同步。
* **激活限制**：每个爱发电订单号与绑定邮箱最多激活 2 次，请妥善保管。
* **第三方模型服务**：使用 AI 功能时，请求会发送至你配置的模型服务商。
* **广告清除边界**：广告清除只隐藏页面节点，不拦截广告请求；视频内广告、反广告拦截墙，以及缺少明显广告特征的原生推广可能清不掉。

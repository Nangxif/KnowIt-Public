在日常浏览网页、阅读文献、工作学习或内容创作时，你是否常遇到以下痛点？
* 🔋 浏览器插件栏日益臃肿，不同插件快捷键冲突、交互凌乱；
* 🔒 担心敏感网页数据被各类在线 AI 或翻译工具上传，泄露隐私；
* 💰 各种小工具收费繁琐，或绑定单一 AI 厂商，缺乏定制灵活性。

**KnowIt** 正是为了解决这些问题而生。它是一款完全运行在本地、隐私优先的模块化浏览器效率工具集。通过创新的**内建应用市场**设计，你可以像搭积木一样，自由开启或关闭各项小工具，打造最符合你个人工作流的**“网页超级工作台”**。

---

## ✨ 核心亮点

* **🧩 模块化应用市场**: 摒弃传统的“大包大揽”模式。提供内置市场，文字搜索、AI 总结、划词翻译、资源下载等小工具皆可一键安装或卸载，按需启用，保持扩展轻量流畅。
* **🔒 极致的隐私保护**: 所有的网页解析、选中文本、搜索记录、翻译历史等，均只存储在您本地浏览器的安全存储区或 IndexedDB 中，绝对不上传至任何第三方服务器。
* **🔑 自由配置的本地 AI**: 统一的模型配置中心，允许您接入自己的 API Key。支持 DeepSeek、OpenAI、Gemini、Moonshot (Kimi)、阿里云百炼、SiliconFlow 等市面上绝大多数主流大模型。
* **🎨 优雅的交互与深浅色模式**: 精致优雅的界面设计，支持悬浮工具栏、快捷键触发以及侧边栏显示，且完美适配系统的深色与浅色模式。

---

## 🛠️ 功能清单

### 🧩 效率工具

* **🔍 增强文字搜索**: 强力网页内文本检索，支持多关键词组合高亮，让长文定位与阅读变得前所未有的简单。
* **📄 智能页面导出**: 智能提取网页正文并去除干扰元素，支持将文章完美渲染并导出为 Markdown、PDF、HTML 或高清图片，自动保留公式与排版。
* **📥 网页资源下载**: 自动嗅探并列出当前网页中的所有图片、视频、音频及 PDF 文件，支持多维度过滤、打包、批量一键下载。

### 🤖 AI 智能辅助

* **📝 网页 AI 总结**: 快速提取长网页、新闻或论文的脉络，生成核心大纲与关键要点，几秒钟读懂万字长文。
* **🌐 双语划词翻译**: 网页选中任意段落或词汇，一键提供精准的多语种对照翻译，长句短句轻松搞定。
* **📖 划词识字助记**: 专为外语学习者设计。划词展示音标、详细释义、生动例句，并能一键加入本地生词本，随时回顾。
* **✍️ 智能写作与润色**: 在网页中的任何输入框内，一键调用 AI 进行段落扩写、精简缩写、语法纠错、语气润色或执行您的自定义 Prompt 创作。

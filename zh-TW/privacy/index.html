歡迎使用 KnowIt。KnowIt 是一款以本地優先為設計原則的瀏覽器擴展，專注提升網頁閱讀效率。本隱私協議旨在說明我如何處理與你使用產品相關的信息，以及這些信息在本地、瀏覽器同步與第三方服務之間的邊界。

第1條 定義

  1. 1.1「KnowIt」指本瀏覽器擴展及其可按需安裝的各類工具，包括但不限於頁內文字查找、內容總結、劃詞翻譯、頁面導出等功能。
  2. 1.2「本地數據」指保存在你當前設備或瀏覽器本地存儲中的信息，例如配置、歷史記錄、激活狀態等。
  3. 1.3「第三方服務」指由你自行配置或選擇使用的外部服務，例如模型服務商、愛發電支付平臺、瀏覽器賬號同步服務等。

第2條 我如何處理數據

  1. 2.1本地優先：網頁內容、選中文字、頁內查找記錄、總結文本、生成結果等，默認僅在本地處理，不上傳至 KnowIt 自有服務器。
  2. 2.2API Key 瀏覽器保存：若你自行配置模型 API Key，該密鑰保存在瀏覽器配置中，可能隨已登錄的 Chrome 賬號在不同設備間同步；KnowIt 不會收集、存儲或轉發該密鑰。
  3. 2.3配置同步：工具安裝狀態、偏好設置等，可能通過瀏覽器自帶的同步能力，跟隨你已登錄的 Google 賬號在不同設備間同步。該同步由瀏覽器服務提供，KnowIt 不運營獨立的雲端賬號系統。
  4. 2.4激活信息：當你購買並激活高級功能時，可能需要填寫訂單號與綁定郵箱，以便完成授權校驗。請妥善保管相關信息。
  5. 2.5新標籤頁聯網搜索：若你在新標籤頁使用搜索框，查詢將通過瀏覽器 Chrome Search API 提交，由你設置的默認搜索引擎處理；KnowIt 不會替換、修改或記錄你的搜索提供商設置與查詢內容。

第3條 第三方服務與數據傳輸

  1. 3.1使用 AI 相關功能時，你主動發起的請求內容會被髮送至你配置的模型服務商。KnowIt 不控制該服務商如何處理數據，請自行閱讀並確認其隱私政策與計費規則。
  2. 3.2支付與激活相關流程可能涉及愛發電等第三方平臺。相關支付信息由對應平臺處理，KnowIt 僅用於完成功能授權所需的必要校驗。
  3. 3.3若你通過 GitHub Issues、郵件等方式聯繫我，你主動提供的聯繫方式與反饋內容將僅用於溝通與問題處理。

第4條 你的權利與選擇

  1. 4.1你可以隨時在擴展設置中修改、清空本地配置與歷史記錄（具體範圍以產品功能為準）。
  2. 4.2你可以選擇是否配置第三方模型服務；不配置時，相關 AI 功能將無法使用或能力受限。
  3. 4.3你可以關閉或退出瀏覽器賬號同步，以減少配置在不同設備間的流轉。

第5條 協議更新與聯繫我

我可能根據產品功能變化更新本隱私協議。更新後的協議將在產品內展示，並自公佈之日起生效。如你繼續使用 KnowIt，即視為知悉並同意更新後的內容。

如對本協議有任何疑問，可通過底部欄公示的郵箱或 GitHub Issues 與我聯繫。
